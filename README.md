## 快速入口

- [分類索引](categories/README.md)

- [情報總索引](INDEX.md)

## 收錄範圍

X.com、Threads、Instagram 公開原始分享，以及工具官方文件與 GitHub 專案。聚焦內容創作、影片、研究、Agent、自動化與中小企業應用。

## 每篇必備

工具名稱、解決問題、三步操作、實際用途、適用對象、費用與限制、原始分享、官方文件、GitHub 連結、查核日期與驗證狀態。

## 來源與品質

1. 優先原始貼文與官方文件；搜尋摘要不等於已讀原文。
2. 分清作者展示、官方確認、編輯推論與親自測試；未實測必須標示。
3. 費用、授權或功能無法確認時明寫未確認。
4. 以原始網址、工具名稱及 GitHub owner/repo 去重，有新功能才更新。
5. 僅摘要與連結，不搬運他人全文、圖片或程式碼。第三方內容依原作者授權。
6. 不收錄密碼、API 金鑰、客戶個資或非公開資料。

## 檔案規則

每日文章放在 daily/YYYY/MM/YYYY-MM-DD.md；結構化資料可放在 data/YYYY-MM-DD.json。新增後更新 INDEX.md 的標題、日期、分類與來源。範本及空索引不代表已收錄實際情報。

## 發布狀態

資料庫架構已建立；FB 自動發布須先完成 Metricool 粉絲頁連接與測試。GitHub 每日自動寫入亦須確認排程執行環境具備本儲存庫寫入權限，不能將建庫成功視為自動同步已啟用。
